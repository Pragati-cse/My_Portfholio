# Personal Portfolio Website

A responsive personal portfolio website built using HTML, CSS, and JavaScript to showcase my technical skills, projects, education, achievements, and certifications.

## Features
- Responsive navigation bar
- Home and About sections
- Technical Skills categorized by domain
- Projects showcase with project links
- Education details
- Achievements and certifications
- Contact section
- Resume download option

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
```text
Portfolio/
├── index.html
├── style.css
├── script.js
├── img/
└── resume/
```

## Deployment
Hosted using GitHub Pages.
